# Language Policy (VI/EN)

## Primary Language
- Vietnamese is primary for local student audience.

## Secondary Language
- English summaries are maintained in top-level README files.

## Writing Rules
- Prefer clear Vietnamese terms.
- Keep technical acronyms in original form: CPU, RAM, SSD, GPU.
- Avoid mixing too many slang/marketing words.
- Keep sentence length moderate for readability.

## Bilingual Rule
- If a term is uncommon in Vietnamese, add English in parentheses once.
- Example: bo nho truy cap ngau nhien (RAM).
