## First Publish Checklist
1. Confirm all relative links work locally.
2. Verify markdown rendering for large tables.
3. Add repository description and topics on GitHub.
4. Enable Discussions (optional) for update requests.
5. Add branch protection and PR template (optional).

## Ongoing Maintenance
- Update price ranges monthly.
- Review model availability quarterly.
- Archive outdated models after 18-24 months.
- Log all meaningful edits in CHANGELOG.
