# Online Global Pricing

International sources can look cheaper but must include full landed cost.

## Common Sources
- Amazon
- Best Buy
- Newegg
- B&H

## Full Cost Formula
Final Cost = Item Price + Shipping + Import Tax + Payment Fees + Warranty Risk Buffer

## Typical Risk Factors
- Different keyboard layout or regional adapter
- Longer warranty claim turnaround
- Return logistics cost
- Import paperwork complexity

## Rule of Thumb
- If net savings < 8-10%, local purchase is usually safer.
- For premium models, compare service coverage first.
