# Price Normalization Rules

Use these rules to compare prices fairly across channels.

## Standard Comparison Unit
Compare only same configuration:
- Same CPU generation
- Same RAM capacity
- Same SSD capacity
- Same panel resolution
- Same GPU tier

## Add-on Cost Buckets
1. Shipping and handling
2. Tax and customs
3. Warranty extension
4. Adapter/keyboard conversion
5. Time cost and return risk

## Normalized Price Template
| Model | Channel | Raw Price | Add-ons | Normalized Price | Notes |
|---|---|---:|---:|---:|---|
| Example Model A | Local | 15.0M | 0.5M | 15.5M | Official warranty |
| Example Model A | Global | 13.8M | 2.1M | 15.9M | Import + return risk |

## Decision Rule
Pick the option with better normalized value and lower support risk, not the lowest sticker price.
