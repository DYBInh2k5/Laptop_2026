## How To Choose a Category
1. Start with your software requirements.
2. Decide whether battery life or raw performance matters more.
3. Set budget ceiling and future upgrade plan.
4. Pick category first, model second.

## Fast Rules
- Office-only users: prioritize battery + keyboard quality.
- Design and editing users: prioritize display + GPU.
- Engineering and simulation users: prioritize CPU + RAM + GPU.
- Frequent travel users: prioritize weight + charger size.
