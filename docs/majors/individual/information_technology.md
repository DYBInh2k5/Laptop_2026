# Cong Nghe Thong Tin

## Muc tieu cau hinh
- CPU: Intel Core i7/Ryzen 7 (toi thieu i5/R5)
- RAM: 16GB toi thieu, 32GB neu AI/VM
- SSD: 512GB-1TB NVMe
- GPU: RTX 4050+ neu ML/CV
- Man hinh: 15-16 inch, FHD/QHD

## Phan mem thuong dung
- VS Code/JetBrains
- Git, Docker
- Python, Node.js, Java
- WSL2/VirtualBox

## Goi y theo ngan sach
- 8-12M: ASUS TUF A15, HP Pavilion Gaming
- 12-18M: Lenovo ThinkBook 16 Pro, MSI GS66
- 20M+: MacBook Pro 14 M3, ROG Zephyrus G16

## Checklist chot mua
1. RAM co nang cap duoc khong.
2. SSD co them slot khong.
3. Nhiet do on khi compile/load.
4. Ban phim, trackpad dung tot cho coding dai gio.
