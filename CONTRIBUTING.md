# Contributing

Thank you for improving this student laptop guide.

## Scope
Contributions are welcome for:
- New laptop models and updated pricing ranges
- Corrections to specs or compatibility notes
- Better guidance for majors and software stacks
- Clearer writing and structure improvements

## Contribution Rules
1. Keep entries practical and student-focused.
2. Prefer verifiable specs over marketing claims.
3. Use consistent format: CPU, RAM, SSD, GPU, display, battery, price.
4. Mark recommendations with clear use-cases.
5. Avoid affiliate links and promotional language.

## Pull Request Checklist
- Updated the relevant section in [Computer_Recommendations_By_Major.md](Computer_Recommendations_By_Major.md)
- Checked link validity and relative paths
- Preserved markdown table formatting
- Added a short note in [CHANGELOG.md](CHANGELOG.md)

## Style Guide
- Write concise bullet points.
- Keep comparisons balanced: strengths and trade-offs.
- Prefer neutral, factual wording.
