# GitHub Release Checklist

Use this checklist before publishing updates.

## Content Quality
- [ ] Verify major sections are complete and consistent.
- [ ] Remove duplicated recommendations.
- [ ] Confirm no broken markdown tables.
- [ ] Validate Vietnamese text rendering (no corrupted characters).

## Link Validation
- [ ] Root links in README.md work.
- [ ] Docs links under docs/README.md work.
- [ ] Internal links to main guide are correct.

## Pricing and Models
- [ ] Update price ranges to current market window.
- [ ] Mark unavailable models with alternatives.
- [ ] Keep at least one option per budget tier.

## Repository Hygiene
- [ ] Update CHANGELOG.md.
- [ ] Review CONTRIBUTING.md for current process.
- [ ] Check .gitignore still matches repository needs.

## GitHub Publish Steps
- [ ] Set repository description and topics.
- [ ] Confirm default branch is correct.
- [ ] Add license if needed.
- [ ] Publish release notes summary.
